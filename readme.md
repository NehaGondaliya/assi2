Breast Cancer Classification: Logistic Regression vs Random Forest

Overview
This project uses Logistic Regression and Random Forest algorithms to classify breast cancer tumors as benign or malignant using the Wisconsin Diagnostic Breast Cancer Dataset. The models are evaluated using accuracy, precision, recall, F1-score, and confusion matrix.

Steps:
Dataset: Loaded from the UCI repository and preprocessed (split into training and testing sets, standardized features).

Model Training:
Logistic Regression: A linear model for binary classification.
Random Forest: An ensemble method with 100 decision trees.

Evaluation: Models are evaluated on test data with performance metrics (accuracy, precision, recall, F1-score) and confusion matrix 

visualizations.
Libraries Used:
ucimlrepo: For loading datasets.
pandas, numpy: For data manipulation.
matplotlib: For plotting confusion matrices.
sklearn: For machine learning models and evaluation.

Results:
Logistic Regression and Random Forest are compared based on their classification performance and confusion matrix analysis.
